# Magazijn Zoeker

Statische PWA voor GitHub Pages.

## Bestanden

- `index.html`
- `style.css`
- `app.js`
- `service-worker.js`
- `manifest.json`
- `artikelen.csv`

## Gebruik

1. Maak een GitHub repository aan.
2. Upload alle bestanden uit deze map.
3. Zet GitHub Pages aan via **Settings > Pages**.
4. Kies branch `main` en map `/root`.
5. Open de GitHub Pages link.

## CSV bijwerken

Vervang alleen `artikelen.csv` door een nieuwe export met dezelfde kolommen.
De app zoekt niet hoofdlettergevoelig en zoekt ook op delen van woorden.
